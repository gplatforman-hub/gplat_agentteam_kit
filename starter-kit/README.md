## 가장 쉬운 길 — 명령어 한 줄 설치

시작 메뉴에서 **PowerShell** 을 열고(관리자 권한 필요 없음) 아래 한 줄을 붙여넣고 Enter.
붙여넣기는 **마우스 오른쪽 클릭**입니다.

```powershell
irm https://raw.githubusercontent.com/gplatforman-hub/gplat_agentteam_kit/main/install.ps1 | iex
```

**CMD 창밖에 안 열리면**(줄 맨 앞에 `PS` 가 없으면) 아래 한 줄을 대신 붙여넣습니다. 파워셸을 잠깐 빌려 똑같이 설치합니다.

```bat
powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/gplatforman-hub/gplat_agentteam_kit/main/install.ps1 | iex"
```

이 한 줄이 스타터킷을 받아 `C:\AgentOffice\01_KIT\starter-kit` 에 설치하고, 환경점검까지 이어서 돌립니다.
같이 만들어지는 **`C:\AgentOffice\MyData\`** 에 내 보고서 3개·회의록 3개(비식별 사본)를 수업 전에 넣어 두세요 (아래).
프로그램(Node·Git·Claude Code)은 없으면 **묻지 않고** 명령어로 깔리고, **Python 은 있어도 무조건 3.14** 가 깔립니다(낮은 버전은 그 자리에서 올라갑니다).
파이썬 꾸러미 설치·확인, 슬랙 열쇠 3개 입력·확인, 서버 첫 기동까지 이어서 합니다. 사람이 할 일은 **로그인과 열쇠 붙여넣기**뿐입니다.
그래서 **슬랙 열쇠 3개(xoxb-·xapp-·멤버 ID)를 먼저 받아 두고** 이 한 줄을 실행하세요 (교안 「슬랙 ①②」 쪽). 인터넷이 켜져 있어야 합니다.

## 시작 전에 — PC 절전부터 끄세요

직원들이 일하는 **서버는 내 PC 안에서 돕니다.** **PC가 절전으로 넘어가면 직원도 같이 잠듭니다** —
검은 창을 안 닫았어도 그렇습니다. 슬랙에 말을 걸어도 아무도 대답하지 않습니다.

**설정 → 시스템 → 전원 및 배터리 → 절전 모드로 전환**을 **안 함**으로 바꿔 주세요.
검은 창에서 한 줄로 끝내려면:

```
powercfg /change standby-timeout-ac 0
```

- **화면 끄기는 그대로 두셔도 됩니다.** 모니터만 꺼지고 서버는 계속 삽니다. 꺼야 하는 것은 **절전** 하나뿐입니다
- **노트북이면 하나 더** — 덮개를 닫아도 절전입니다. **제어판 → 전원 옵션 → 덮개를 닫을 때 수행할 작업**을 **아무 것도 안 함**으로
- `py 점검.py 8` 이 이 설정을 자동으로 확인합니다 — `PC 가 절전으로 안 넘어간다` 줄

## 내 양식 미리 넣기 — `C:\AgentOffice\MyData\`

설치가 이 폴더를 만들어 둡니다. 부록 A(내 양식)에서 직원이 **내 보고서 구성·말투**를 여기서 배웁니다.
**수업 전날까지** 넣어 두면 당일이 편합니다. 없는 칸은 비워 두어도 수업은 진행됩니다.

> 🔒 **회사 원본을 그대로 넣지 마세요.** 사본을 만들어 회사 이름·사람 이름·고객사·금액을 `○○` 로 지운 뒤 넣습니다.
> 회사 규정상 사본도 가져올 수 없으면 **빈 양식(제목과 항목 이름만)** 을 손으로 적어 넣으세요.

| 폴더 | 넣을 것 | 개수 |
|---|---|---|
| `MyData\Report\` (보고서) | 내가 쓴 주간보고·업무보고 (docx·pptx·pdf·hwp·txt) | **3개** |
| `MyData\Minutes\` (회의록) | 내가 정리한 회의록 | **3개** |
| `MyData\Track\` (직무 문서) | (선택) 제안서·블로그 글·안내문·기획서·비용표 중 내 직무 것 | 3개 |

**`Skill` 칸은 이미 클로드를 써 오신 분만** 채우면 됩니다. 넣어 두면 부록 A 에서 그 스킬이 **그 일의 정본**이 되고, 수업에서 만든 뼈대 스킬은 `_보관` 으로 물러납니다. 처음이시면 비워 두세요 — 수업에서 처음부터 만듭니다.

폴더 이름이 영문인 것은 프로그램이 한글 경로에서 막히는 일을 없애기 위해서입니다. 폴더 안의 `여기에_넣으세요.txt` 에 같은 내용이 적혀 있습니다. 환경점검 「선택」 항목에 몇 개 들어갔는지 표시됩니다.

## 합격 판정 받는 법

모듈이 끝날 때마다 Code 탭에서 클로드에게 **"`py 점검.py 3` 실행하고 결과 보여 줘"** 라고 합니다. **점검 번호 = 모듈 번호**입니다.

```
py 점검.py 0     ← 출발선 (설치 직후)
py 점검.py 2~8   ← 각 모듈이 끝났을 때
py 점검.py 9     ← 전체
py 점검.py 10    ← 부록 A 내 양식
```

✅ 가 전부 켜지면 다음으로 넘어갑니다. ❌ 가 있으면 **그 줄만** 고치면 돼요.
`py` 가 안 먹으면 Claude 앱을 완전히 껐다 켜거나 `py -3 점검.py 3` 로 해보세요.

**`점검.py` 는 고치지 마세요.** 여러분이 만든 게 규격에 맞는지 보는 채점표입니다.

## 이름 끝에 `.txt` 가 붙은 파일

`_예시_직원.md.txt` 처럼 `.txt` 로 끝나는 건 **보라고 넣어둔 견본**입니다.
채점에는 안 들어가니 열어보고 참고만 하세요. 여러분이 만드는 진짜 파일은 `.txt` 없이 만듭니다.

## 직원이 한 일은 자동으로 남고, 지우는 일은 꼭 묻습니다

스타터킷에 **안전장치**가 들어 있습니다 (`.claude/settings.json` + `.claude/hooks/`). 켜거나 설정할 것은 없습니다.

| 무엇 | 어떻게 |
|---|---|
| 자동 기록 | 내가 친 명령·직원이 만들고 고친 파일이 `workspace/기록/작업기록_<날짜>.md` 에 한 줄씩 남습니다 |
| 자동 저장 | 직원이 답을 마칠 때마다 git 에 자동 저장 지점이 생깁니다 (모듈 1 카드 P1-c 의 `git init` 이후). `git log --oneline` 으로 봅니다 |
| 삭제·덮어쓰기 확인 | 파일 삭제 · 기존 파일 덮어쓰기 · 직원/스킬/팀 규약 수정 · `git checkout`류는 실행 전 **확인 창**이 뜹니다. 고르기 전엔 실행되지 않습니다 |
| 못 고치는 것 | `점검.py` · `.claude/settings.json` · `.claude/hooks/` — 직원이 수정하려 하면 막힙니다 |
| 슬랙 | 확인 창을 띄울 곳이 없어 삭제·덮어쓰기를 **막고** "터미널에서 진행해 주세요"라고 답합니다. 고장이 아닙니다 |

## 막혔을 때

| 증상 | 이렇게 |
|---|---|
| `py` 를 모르는 명령어래요 | Python 이 안 깔린 겁니다. 검은 창을 새로 열어보고, 그래도 안 되면 손 드세요 |
| 한글이 깨져 보여요 | 검은 창에 `chcp 65001` 치고 다시 실행 |
| AI가 엉뚱한 파일을 고쳤어요 | 클로드에게 "아까 저장 지점으로 되돌려 줘" — git 저장 지점에서 되살립니다 |
| ❌ 가 안 없어져요 | 카드를 한 번 더 그대로 붙여넣으세요. 덮어씁니다 |
